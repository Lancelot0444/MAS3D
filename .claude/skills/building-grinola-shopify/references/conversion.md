# CRO Grinola

Objetivo:
Incrementar add-to-cart, checkout y compra.

Prioridades:

1. Claridad del producto.
2. Precio visible.
3. CTA visible.
4. Fotografías excelentes.
5. Beneficios concretos.
6. Información de envío clara.
7. Confianza.
8. Checkout rápido.

No usar:
- falsa escasez
- contadores ficticios
- reviews falsas
- descuentos inventados
- urgencia engañosa

Para Limited Editions:
mostrar stock real cuando Shopify pueda gestionarlo.

Usar:
“Edición limitada”
solo si realmente existe límite de fabricación o inventario.

# Catálogo Grinola

## Arquitectura

### Core Collection
Productos funcionales disponibles regularmente.

Ejemplos:
- Pocket Case
- Celtic Pocket Case
- Rolling Station
- Grinder Classic
- Grinder Sphere
- Skull Flame Case

### Limited Editions
Productos coleccionables y de producción limitada.

Subcolecciones:
- Anime Editions
- Fantasy Editions
- Sweet Editions

Ejemplos actuales:
- Samurai Green Edition
- Shadow Ninja Edition
- Chibi Blush Edition
- Fantasy Fruit Purple
- Fantasy Fruit Orange
- Cupcake Sweet Grinder

## Producto

Cada ficha debe contener:

1. Nombre
2. Fotografías
3. Precio
4. Descripción corta
5. Características
6. Tamaño
7. Material
8. Color / variantes
9. Stock o disponibilidad
10. Tiempo de preparación
11. Envíos
12. Botón Comprar
13. FAQ contextual
14. Productos relacionados

## Filosofía

Los productos deben venderse principalmente desde Shopify.

WhatsApp es soporte secundario, no el canal principal de ventas.

El usuario debe poder:

Producto → variante → carrito → pago

sin conversación manual.

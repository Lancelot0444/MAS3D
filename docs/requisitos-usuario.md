# Lo que Grinola necesita del dueño

1. Logo (o aprobar la propuesta que diseñe Claude).
2. Por producto: nombre, precio USD, variantes, medidas, material, tiempo de preparación, stock / bajo pedido, unidades si es edición limitada.
3. Fotos de cada producto (mínimo 3: frontal, detalle, en uso/escala).
4. Envíos: zonas, courier, costo por zona, ¿envío gratis desde X?, ¿retiro en local? (ciudad y dirección).
5. Datos legales: razón social o nombre, RUC, dirección, correo y WhatsApp de soporte.
6. Pagos: solicitar cuenta Kushki (y/o PayPhone); datos bancarios para transferencia/DeUna.
7. Políticas: ¿aceptas devoluciones? ¿en cuántos días? ¿quién paga el envío de vuelta?
8. Dominio deseado (ej. grinola.ec / grinola.com).
9. Redes: Instagram y TikTok.
